Name of Quantlet: Bitcoin Return Direction Prediction——with Deep Learning and Interpretable Features

Published in: Blockchains, Crypto Currencies, Network Analytics (BCN-XMU-course2026)

Description: This project builds a reproducible end-to-end pipeline for next-day Bitcoin return direction prediction using market, on-chain, macro, and sentiment features. We compare baseline models (Logistic Regression L1, Random Forest) and a GRU model under strict leakage control, then evaluate all models with a unified financial backtesting protocol. Results show weak but non-zero predictive signal; the main contribution is methodological rigor, fair model comparison, and interpretable feature analysis with SHAP.

Submitted: Duan Kaifeng, 02. April 2026

Keywords: Bitcoin, Return Direction Prediction, Time Series Classification, GRU, Logistic Regression, Random Forest, SHAP, Leakage Control, Unified Backtesting, Quantitative Finance, Crypto Analytics, Reproducible Pipeline

Author: Wolfgang Karl Härdle, Duan Kaifeng, Xia yi, Zheng Wenxin, Kuang Xuan, Duan Shunxin
