Description: Byzantine Fault Tolerance Consensus Algorithm Simulation.This course project focuses on the core consensus mechanism of blockchain—the Practical Byzantine Fault Tolerance (PBFT) algorithm. It simulates the core three-phase consensus process purely logically using Python, validating the core conclusion of the PBFT algorithm: when the number of malicious nodes in a distributed system does not exceed one-third of the total nodes, the system can achieve consistent decision-making among honest nodes; when the number of malicious nodes exceeds one-third, the system cannot reach effective consensus. This project requires no external data, no internet connection, and no real blockchain environment. It merely simulates node interactions and message passing to replicate the three stages of the PBFT algorithm—pre-prepare, prepare, and commit—intuitively demonstrating the core principles of Byzantine fault tolerance.
