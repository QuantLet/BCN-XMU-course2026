Name of Quantlet: Zero-Knowledge Proof based Blockchain Transaction Visualization with GNN Risk Prediction 

Published in:     Class BCN-XMU-course2026

Description:      This project has developed an interactive web application that demonstrates privacy-preserving blockchain transactions based on zero-knowledge proofs, and performs P2P visual network analysis on transaction data.  It also performs GNN-based risk prediction using real-world transaction datasets. This project aims to provide an intuitive demonstration of the privacy transaction process, network structure and model performance, whilst offering an interactive verification tool for blockchain privacy transactions and risk management.

Keywords:         zero-knowledge proof, blockchain privacy transaction, P2P visual network, GNN risk prediction, model evaluation
