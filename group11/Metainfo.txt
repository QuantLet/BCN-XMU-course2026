Name of Quantlet: Ethereum Fraud Detection 

Published in:     Class BCN-XMU-course2026

Description:      For this project, we use exploratory data analysis (EDA) to find the key factors that truly affect Ethereum transaction fraud results, and handle outliers and potential correlations among features. We carry out full data preprocessing, feature engineering and PCA dimensionality reduction to optimize data quality. We build prediction models including Logistic Regression, Random Forest, SVM and etc., test their accuracy, compare model performance, and finally select the most suitable classification method for Ethereum fraud detection.

Keywords:         Ethereum, PCA, machine learning, python

Author:           Yang Zhang, Jialu Chen, Yuhuan Guo, Jiacheng Chang
